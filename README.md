# 微光 · 化学实验室

一个原创的 Three.js 浏览器化学实验室体验。房间、家具、试剂瓶标签、器具与实验界面均由本项目代码程序化绘制，不引用其他项目的素材或实现。

## 公网访问

GitHub Pages 站点：https://invincible-summer.github.io/chemistry-perform/ 。推送到 `main` 或本次工作分支后，会由 GitHub Actions 自动部署。

## 运行

```bash
npm install
npm start
```

服务默认监听 `0.0.0.0:8080`，访问 `http://localhost:8080`。项目无打包器或运行时框架，唯一运行依赖是 Three.js。

## 操作

- 鼠标拖动空白场景旋转视角，滚轮缩放。
- 选择左侧试剂，再点击一个器皿加入；也可以点击三维场景里的试剂瓶，再点器皿。
- 拖动器皿可重新摆放，点击器皿可查看体积、温度、pH 与组分。
- 左侧工具栏或按 `1–6` 切换工具；选择器皿后按 `H` 或点“开始加热”。
- `?` 打开实验灵感；“重置实验”清空所有器皿。

## 教学说明

反应表现是供交互观察的定性模拟，不用于真实实验操作指导；真实实验请遵守教师指导与实验室安全规范。
